# 千年木艺 · 方案工坊 V1

基于用户提供的 `wood网页.gz` 第一版网站。保留原站“千年木艺”名称、深色底色、琥珀金主色、中文排版、渐变卡片与木作主题，围绕一个完整的桌面双层置物架案例重构设计流程。

## 本地启动

环境：Node.js 20 或更新版本。没有 npm 依赖，不需安装包，不需 API 密钥或联网。

Windows 双击 `启动预览.cmd`，浏览器会自动打开预览。若已运行，会复用现有地址；若默认端口被其他应用占用，会自动选择后续可用端口。保持终端开启，关闭终端即可结束本次服务。

也可以在此目录运行：

```sh
node server.mjs
```

若端口占用，可在 PowerShell 中运行 `$env:PORT=4175; node server.mjs`，然后打开对应端口。不支持直接双击 index.html，因为浏览器模块及申请保存依赖 HTTP 服务。

## 已实现

- 完整案例：案上双层置物架，标准款与紧凑款两种可用预设，共 4 件木构件。
- 需求文本输入与保存。需求供人工审核参考；没有接入大模型，不会根据任意自然语言生成家具。
- 总宽、总高、总深、板厚与木材外观选择；整数和范围检查。更新方案后模型、尺寸、材积、构件清单同步变化；导出或申请时也检查当前输入。
- 本地三维正交投影模型：拖动旋转、滚轮缩放、视角重置、爆炸滑杆、整体模式、构件点击高亮；可用 Tab 与 Enter 选择模型编号，也可从构件清单选择。
- 两块侧板真实几何分段形成两道贯通槽，层板长度包含入槽长度。模型为设计名义几何，不含加工公差、倒角或刀具路径。
- 构件档案、4 行构件清单、名义材积。
- 5 步装配参考、检查点、模型构件提示与完成进度。改变参数会重置学习进度。
- 完整方案 JSON（参数、构件、教程、验证边界）、UTF-8 BOM CSV；打印版方案可通过浏览器打印保存 PDF。
- 当前草稿及学习进度保存在浏览器 localStorage。
- 加工申请保存到本机 `data/applications/<uuid>.json`，含不可变方案快照、备注、时间与“待人工确认”状态。刷新和服务重启后可读取，可下载申请快照。
- 输入错误、服务不可用、文件保存失败等情况显示错误；请求保存失败不会显示成功状态。
- 桌面与手机响应式布局。

## 业务与工程边界

这是可运行的本地设计与教学原型，不能直接作为加工依据。

1. **结构工程**：未做承载、侧向摇摆、抗倾覆、连接拔出强度或耐久试验。四板框架尤其需要工程人员评估抗侧向变形与加强方案，不声明任何额定载荷。
2. **木材与配合**：槽深暂取板厚的 1/3，槽宽暂等于板厚；这是参数化示意规则，未验证木材含水率、湿胀干缩、配合公差、胶合或锁固工艺。
3. **制造交付**：清单为名义外包尺寸，没有开料余量、优化排料、纹理方向图、完整工程图、DXF/STEP、CNC 路径、刀具补偿或工艺签审。材积为毛坯外包体积之和，不是扣槽后的净材积或采购报价。
4. **教程**：虚拟理解流程，未通过实物试装验证。完成教程不代表工程验收。未经工程确认和样件试验，勿直接制作并承重使用。
5. **加工申请**：仅本机持久化；没有通知审核人、后台审批、支付、厂商接口或自动下单。需要用户自行导出后交给工程人员。
6. **部署**：默认只监听 127.0.0.1；设置 `NODE_ENV=production` 后监听 0.0.0.0，使用平台提供的 `PORT`。尚未实际部署。公开收集申请前仍需适配 HTTPS 请求、持久化存储及访问权限。
7. **原站模块**：本版聚焦新的完整案例；未迁移原站六类榫卯百科、Coze AI 导师、AR 与认证模块，不把这些展示入口作为已实现能力。

## 数据规则

### 通过网站地址访问

部署到服务器后，电脑和手机均可通过平台提供的公开 HTTPS 网站地址访问。手机布局自动适配，不需要额外的手机预览启动器。部署设置使用 `NODE_ENV=production`，不再使用 `WOOD_LAN`。

设计草稿和教程进度仍分别保存在各浏览器，不会跨设备实时同步。普通“启动预览.cmd”仅供电脑本机使用。

- 总宽 360–800、高 320–600、深 180–320、板厚 18–24，单位 mm，均为整数。
- 侧板：高 × 深 × 板厚，左右镜像；上下槽外缘距对应端面 60 mm。
- 槽深 `g = round(t / 3, 2)`；层板长 `w - 2t + 2g`。
- 修改草稿不会追溯修改已保存的加工申请。申请 ID 为随机 UUID。
- 数据备份：备份 `data/applications/` 即可保留加工申请；浏览器草稿需要导出 JSON。当前版本未提供 JSON 导入功能。

## 源码结构

```text
public/index.html     页面结构
public/style.css      视觉风格、响应式与打印样式
public/model.js       参数规则、构件、教程及导出数据（前后端共用）
public/viewer.js      无第三方依赖的三维投影、槽口几何及交互
public/app.js         页面状态、输入、导出与申请交互
server.mjs            本地 HTTP 服务、校验及申请文件持久化
test/core.test.mjs    参数和持久化接口回归测试
启动预览.cmd          Windows 启动入口
```

原包为 Next.js / React / Three.js 项目。本版将该视觉体系和构件展示思路重构为可离线运行的原生 JavaScript 与 Node.js 小型应用，以避免原项目的 Coze 服务、Bash 脚本及大量依赖影响本地启动。三维采用 SVG 承载三维几何投影，不是 Three.js/WebGL，也不是可制造 CAD 内核。
