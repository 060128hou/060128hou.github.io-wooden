# 千年木艺 — GitHub Pages 在线体验版

纯静态网站，可放在 GitHub Pages 仓库根目录发布，无 Node.js 服务器、无银行卡或工厂支付功能。

保留需求输入、尺寸模板、三维旋转与爆炸图、构件档案、构件清单、教程、JSON/CSV 导出和打印。

申请仅保存在每位访客当前浏览器内，固定“待人工确认”，可以导出 JSON 交给审核人。不会提交至网站运营者，也不会跨设备同步；清除浏览器数据会丢失未导出的申请。真实在线收件需要后续接入有权限控制的后端。

将本文件夹内文件（不是 ZIP 或外层文件夹）上传至仓库根目录，确保根目录直接有 index.html、app.js、applications.js、model.js、viewer.js、style.css。Settings → Pages 使用 main 分支 / (root)。本版用相对资源路径，支持项目子路径。

请勿将原版 data/applications 中的私人申请上传至公开仓库。已上传的真实记录需要另外处理删除及历史记录中的暴露。

所有尺寸仍是设计名义值，承载、抗倾覆、公差、胶合工艺及实物装配未经验证。本版不是加工图纸。
