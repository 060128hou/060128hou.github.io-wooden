# 桌面营造工坊的功能边界

## 已实现

- 首页展示原 OBJ 中的两组完整木构架，分别按 5 个空间层级查看、隐藏与展开。
- 保留中式斗拱（52 构件 / 12 步）、宋式四铺作（27 构件 / 15 步）及原有置物架的参数与装配页面。
- 7 种桌面搭建模块：台座、方柱、横梁、屏板、层板、斗拱组、双坡顶组；添加、点选、拖动坐标轴、5 mm 网格、接近承托面时自动对齐、90° 旋转、尺寸和位置输入、复制删除、撤销重做。
- 3 个起点：四柱小亭、一扇花窗、空白台面。单份作品最多 80 模块。
- 从 `花纹.FBX` 提取 18 款原始纹饰，作为真实几何浮雕叠放在指定平面。支持正面、背面、两侧和顶面、大小、角度、横纵偏移、木材外观；超出表面时预览自动限制到面内。
- 自动模块装配规划、播放暂停、上下一步、重播、进度拖动和连播；构件编号在清单、教程和导出之间保持一致。
- PNG 当前视角渲染、JSON 完整方案及教程、CSV 构件清单、JSON 导入。
- 浏览器自动草稿、登录后的云端独立快照、公开只读分享、撤销分享。
- 站内客服：提交真实方案快照与消息，工作人员接待列表、读取参数、回复、更新状态和人工报价。数据存储在 D1 / R2。
- AI 生图页面与服务器适配，未配置供应商时关闭生成，不使用假图片。
- 19 款说明书对应的三维展示模型，覆盖四至八铺柱头与补间、五至八铺上昂、五铺转角、七踩鎏金和建筑节点。独立几何、编号、编排步骤、逐步动画、构件点选、爆炸图、外观比例调整与 PNG / JSON / 展示清单导出。
- 模型馆分类和搜索、模型步骤链接、本机预览记忆、云端模型快照、三维分享页面与客服模型参数传递。用户页面不展示说明书 PDF 或图纸。

## 说明书模型的重建范围

19 款模型按可见外形和构件关系分别重建，包含 1,177 件**展示构件**和 436 个编排步骤。展示分件可以合并实物零件，不能将这些数字视为经过核对的料包数量。所有坐标、外廓和缩放均为比例展示单位，未标定实际毫米尺寸。

装配演示使用每个模型独立编排的构件顺序和移动方向。动画与模型共享编号和终点坐标；隐藏榫口、公差、准确插入方向、无干涉路径与实物顺序仍需工坊和样件验证。它与自由搭建区的模块规划是两套不同的规则，不能用模型展示动画替代生产装配审核。

“佛光寺檐侧.pdf”的正文标题与图示仍为山侧。该文件对应条目命名为“佛光寺山侧斗拱 · 梁枋异版”，保留可观察的梁枋差别，不将文件名直接认定为另一个檐侧结构。“山门.pdf”和“山门 檐.pdf”用于同一独乐寺节点；重复提供的同款说明书合并建模。

三维馆不包含 PDF、扫描图或原图查看入口。原始资料和内部解析材料留在开发工作区，部署包只包含模型网格、渲染封面和教程数据。

## 自动教程具体支持什么

规划根据最终的模块位置、尺寸、朝向与接触面重新计算，**不依赖拖动历史**。以向下放置的标准模块为边界：

- 台座平放在地面；柱、屏板、斗拱中心需要对准下方承托面。
- 横梁两端各有独立承托；层板和顶架至少有两处分离承托。
- 按支撑依赖拓扑排序，检查悬空、包围盒重叠和简化的向下装入路径。
- 未通过时阻止播放“有效教程”，显示受影响构件和调整原因。
- 斗拱与屋顶是预装模块。斗拱组内部有单独的原有教程，自动规划不推导内部榫卯。

这是受规则约束的**模块级演示**，不支持任意上传网格后自动求解所有榫卯或施工顺序。复杂斜向插接、穿插、形体精确碰撞、重心与倾覆、工具空间、连接强度均未求解。包围盒检查采用保守近似，不能替代实物装配验证。

## 素材的实际使用

- `中式斗拱-3.obj`：完整木构架 A 对象 445–4488，B 对象 4630–6095；保留源几何，合并绘制组并 gzip 压缩。源文件未标注可靠实物单位，馆藏模型不宣称毫米尺寸。
- `花纹.FBX`：在完整父级变换下提取 18 款独立纹饰；归一化后用于外观预览。来源对象名记录在纹饰 catalog.json。
- C4D / MAX 文件原样保留在用户原目录，没有声称已解析这两种专有格式。当前使用可读取的 FBX / OBJ。
- 其余大量花纹仍保留在原 FBX 中，本轮精选 18 款；并非将整个原素材包全部公开。

## 仍需实际资源或工程确认

1. AI 外包方提供 HTTPS 接口、测试密钥及正式额度，再进行真实生图验收。
2. 桌面成品的实际尺寸、榫卯加工、材料、公差、承载与装配顺序由工坊确认并制作样件。
3. 两组大型构架只有空间分层观察，没有从原文件得出可靠的逐件施工说明。需要对应构件表与拼装说明后才能补全建筑装配教程。
4. 纹饰只是表面视觉预览，不生成雕刻刀路，也不承诺实际雕刻深度或加工可行性。
5. 客服为站内留言和人工接待，不自动在线答复、不发微信 / 短信、不接支付和工厂自动下单。工作人员需要登录工作台查看和回复。
6. 云端记录需要访客使用 ChatGPT 账号登录；未登录访客可以浏览、搭建、导出和保存本机草稿。
