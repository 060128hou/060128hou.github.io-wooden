- 全部 19 个模型均有独立几何指纹；检查三角网格、有限坐标、正尺寸、唯一构件编号，以及构件和步骤的一一归属。
- 真实 Chrome 逐一载入全部模型，生成实际渲染封面；浏览器没有脚本错误。人工查看整馆模型图和建筑节点形态。
- 模型馆组合筛选、构件名称搜索、无匹配恢复、错误模型链接恢复。
- 爆炸视图、播放暂停、动作进度、上下一步、重播、三维表面点选、编号列表联动。
- 下载实际 PNG、JSON 和 CSV，核验文件内容与当前模型编号、展示构件数量。
- 外观与比例在本机刷新后保留；步骤链接正确打开。
- 在隔离的本地数据库上提交待人工接待方案，工作人员可打开当前模型参数；云端快照分享以三维模型显示。
- 1480px 桌面与 390px 手机视口检查，无横向溢出；手机端装配控制可用。
- 上述端到端流程共 32 项检查通过。数据和服务端参数检查通过项目测试执行。

## 仍需验证

模型是比例展示复原。真实尺寸、暗榫、木材、公差、装配路径、承载能力及历史工艺定位需要制作方确认与样件验证。未把生成动画当作实物装配已通过的证据；不输出可直接生产的刀路或开料图。手机检查使用 Chrome 移动视口，尚未覆盖所有真实 iOS / Android 设备。

## 编辑与复现

`scripts/teaching/` 保存几何和步骤生成逻辑，`npm run models:build` 可重新生成压缩模型与目录统计。`public/assets/teaching/*.json.gz` 为访客加载的网格数据；同名 WebP 为实际模型渲染。`lib/teaching.ts` 定义统一数据类型，`components/Scene.tsx` 负责三维绘制和按步骤移动。
