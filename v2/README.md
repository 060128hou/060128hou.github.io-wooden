在浏览器里调整木作尺寸，逐步试装四件式双层置物架或两件式十字分格架。手机和电脑共用一个地址。[打开工作台](https://060128hou.github.io/060128hou.github.io-wooden/)

新增「中式斗拱」独立案例，直接保留用户 OBJ 中一组斗拱的 52 个网格对象及 14,868 个三角面，组织为 12 步分层演示。支持构件表面点选、旋转、缩放、爆炸、播放、暂停、重播、连续播放与前后步骤切换。[打开中式斗拱](https://060128hou.github.io/060128hou.github.io-wooden/?case=chinese)

中式斗拱保留源模型单位，未换算为毫米。整体比例可调为 60%–140%，构件外廓、拆解间距和动画终点同步变化。源文件缺少材质文件，网站使用可切换的木材外观。52 个网格分件不等于已审定的 52 件加工件；教程依据空间层次编排，隐藏榫口、实际插入路径、构件称谓及实物尺寸仍待核对。

原有宋式斗拱保留 27 个展示分件与 15 步演示。[打开宋式斗拱](https://060128hou.github.io/060128hou.github.io-wooden/?case=dougong)。已移除顶部说明栏、原拼装图入口及网站内的原图文件。

原图没有尺寸标注，标准展示外廓设为 264 × 302 × 350 mm，可以在 60%–140% 之间等比例调整。尺寸、暗榫、分件边界和局部前后关系均待实物核对。动画按图中拆分方向分步落位，实际暗榫插入路径需要后续确认。页面、清单及导出方案均保留这一说明。

宋式斗拱由 `dougong.js` 和 `mesh.js` 定义几何与动作。中式斗拱由 `chinese.js` 定义教程，`chinese-data.js` 保存源对象编号和几何范围，`assets/chinese-dougong.bin` 保存重定位后的原始三角面与面法线，`gpu.js` 使用 WebGL 深度缓冲绘制和点选。未重建或简化源轮廓。模型来自 OBJ 对象 `多边形_103` 至 `多边形_154`，只是平移到展示原点；整套建筑场景未打包到网站。全部模型共用参数、播放器、清单及导出流程。

## 本地运行

安装 Node.js 20 或更新版本，解压源码，在 Windows 上双击「启动预览.cmd」。保持第一个窗口开启即可。也可以在源码目录运行以下命令，再打开终端显示的地址。

```sh
npm start
```

这个版本没有第三方运行依赖。默认地址是 `http://127.0.0.1:4182/`。重复启动会复用正在运行的第二版预览，端口被其他程序占用时会选择空闲端口。

## 试用两个案例

1. 打开「案上双层置物架」，修改总宽度或上下留边，点击「应用参数」。例如，使用标准款和 18 mm 板厚时，把总宽改为 450 mm，B1、B2 的名义长度会变为 426 mm，左右各入槽 6 mm。
2. 在「分步试装」点「装入下层板」观察 B1 与 L1，点「同时合拢两处槽口」观察 A2 与 R1、R2。动画支持播放、暂停、重播和前后切换。点模型标签可看构件尺寸图和接口定位。
3. 用「切换木作案例」选择「十字分格架」。将 C2 移到 C1 的正上方，播放「垂直交叉对插」，观察两块半槽板的上、下边齐平。
4. 在「构件清单与料包标签」导出 JSON 方案、CSV 清单，打印标签或方案。方案可用浏览器打印为 PDF。在「参数校验与样件验证」打印带构件图、名义尺寸和实测栏的检查单。
5. 加工申请保存在本浏览器，状态为「待人工确认」。用「导出申请」把该次的方案快照交给审核人。申请与草稿使用设备本地存储。网站不收款，也不向工厂下单。

## 模型与验证

两例共用参数校验、构件与接口编号、动画播放器、清单及打印流程。`model.js` 的案例定义提供各自的开槽几何、装配顺序、关键帧和复核项。`viewer.js` 根据这些数据绘制可旋转的三维投影，按当前尺寸计算每一步的移动与接口位置。`reports.js` 从同一份几何数据生成尺寸图。

运行以下命令可重复检查 198 组参数，包括 176 组有效组合和 22 组应被拒绝的组合。测试在有效组合的 20,832 个采样姿态上检查构件实体相交、穿过台面、相邻步骤衔接及最终就位。

宋式斗拱检查 4 种比例、27 件分件、型面共面性以及 300 个教程采样状态。中式斗拱检查二进制校验和、原始网格外廓、52 个分件的完整对应、4 种比例和 240 个教程采样状态，以及导出单位与来源。浏览器验收包含实际表面点选、连播暂停、导出、案例切换和 390px 手机布局。这些检查覆盖展示数据及动画状态，不代替实体榫口与路径试装。

### 待样件与工艺确认

槽深取板厚约三分之一、层间净高下限等是置物架的设计设定。两个案例使用名义配合。实物须以同批木料试切，测量实际板厚与槽宽，确定加工余量、公差、含水率、固定与支撑方式，再验证承载、稳定和耐久。检查单预留实测与复核签字。当前两个案例均待样件试制和专业复核，传统木作工艺定位待传承人确认。

「使用需求」随草稿和方案保存。自然语言自动填参尚未接入。加工申请仍保存在当前浏览器，状态为待人工确认，不连接支付或工厂自动下单。
